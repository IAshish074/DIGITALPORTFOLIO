## 🛠️ Technology Stack

This portfolio is divided into a frontend and a backend to support dynamic features like contact form submissions and newsletter subscriptions.

### Frontend
- **React.js (v19)** - Component-based UI development
- **Vite** - Lightning-fast frontend tooling
- **Tailwind CSS (v4)** - Utility-first styling for a premium dark mode aesthetic
- **Framer Motion** - Smooth scroll animations and interactive UI transitions
- **React Scroll** - Seamless section navigation
- **React Icons** - Lightweight, scalable vector icons

### Backend
- **Node.js & Express.js** - Robust server and API handling
- **Nodemailer** - Seamless email delivery for the contact and subscription forms
- **Dotenv** - Secure environment variable management

## ⚙️ How to Run Locally

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### 1. Clone the repository
```bash
git clone https://github.com/IAshish074/My_PORTFOLIO.git
cd My_PORTFOLIO
```

### 2. Setup the Backend
Navigate to the server directory, install dependencies, and setup your environment variables.
```bash
cd server
npm install
```
Create a `.env` file in the `server` directory and add your Gmail credentials:
```env
EMAIL_USER=your-email@gmail.com
EMAIL_PASS=your-app-password
PORT=5005
```
Start the backend server:
```bash
npm start
```

### 3. Setup the Frontend
Open a new terminal window, navigate to the frontend directory, and start the development server.
```bash
cd frontend
npm install
npm run dev
```

The application will now be running at `http://localhost:5173`.
